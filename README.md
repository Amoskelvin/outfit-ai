\# AI Outfit Recommendation System



An AI-powered application that suggests the best outfit combinations based on your wardrobe.



\## Features

\- Upload clothing images to build your digital wardrobe

\- AI-powered outfit recommendations

\- Color and style compatibility analysis

\- Occasion-based suggestions



\## Tech Stack

\- \*\*Backend:\*\* FastAPI, Python 3.14

\- \*\*ML/AI:\*\* PyTorch, Transformers, OpenCV

\- \*\*Database:\*\* PostgreSQL

\- \*\*Image Processing:\*\* Pillow, OpenCV
